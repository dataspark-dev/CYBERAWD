# Cyber Security Awareness Month — Campaign Calendar, Alignment & Rehearsal Plan

Companion to [LIVE-GAMES-EXECUTION-PLAN.md](LIVE-GAMES-EXECUTION-PLAN.md) (single-session run-of-show for the 2 live team games) and [slides/slide-19.html](slides/slide-19.html) (the deck's "Take It Further" announcement slide). This document answers a different question: **how do all 4 games fit into a month-long awareness campaign**, alongside the existing training deck, and how do organizers make sure each one actually works before real participants see it.

## 1. Campaign overview

The 4 games split naturally into two delivery modes, based on their own stated requirements:

- **Self-paced digital games** — no facilities or facilitator overhead, can run company-wide over several days: *Digital Platform — Cybersecurity Game* (InfosecIQ link) and *Digital Platform — Fault Finding* (a display screen in a common area).
- **Live team games** — need groups, facilitators, stencils, and a scheduled block of time: *Cyber Clue Quest* and *Pass-Phrase*. These two become the campaign's capstone **"Live Games Day"**, reusing the team/timer/scoring mechanics already defined in `LIVE-GAMES-EXECUTION-PLAN.md` rather than duplicating them here.

This lets the two low-overhead games run continuously in the early weeks (building awareness and completion numbers), while the two high-engagement live games close out the month as a single memorable event.

## 2. Month-at-a-glance calendar

Weeks are aligned to the training deck's existing content groups (see `deck-manifest.md`'s Flow Map) so each game reinforces material just covered. Week boundaries are illustrative — shift them once the campaign's actual start date is set.

| Week | Deck content focus | Activity | Delivery mode |
|---|---|---|---|
| 1 | Welcome, Threat Landscape, Deepfake Attacks | **Launch:** Digital Platform — Cybersecurity Game | Company-wide link/email, self-paced |
| 2 | Phishing Evolution, AI & Chatbot Risks | Digital Platform — Fault Finding | Walk-up display screen in common area(s) |
| 3 | Workplace Security, Do's & Don'ts | Catch-up window for both digital games + rehearsal/dry-run window (§4) + Live Games Day promotion | Comms + prep, no new content |
| 4 | Closing / recap | **Live Games Day:** Cyber Clue Quest + Pass-Phrase (rotating stations per `LIVE-GAMES-EXECUTION-PLAN.md`) | In-person, scheduled block (~40 min) |

## 4. Pre-event rehearsal / dry-run plan ("simulation execution")

A test pass by organizers/facilitators only — no real participants — run before each game's go-live week, ending in a short go/no-go checkpoint so there's time to fix a gap before it's seen live.

| Game | Rehearsal checklist | When |
|---|---|---|
| Cybersecurity Game (InfosecIQ) | Confirm the shared link resolves on the corporate network; the ~30s video plays without buffering; the follow-up question fires correctly; completions are tracked/reportable | ~3–4 days before Week 1 |
| Fault Finding | Run one full mock round with 2–3 staff on the actual display screen; confirm every scenario image is legible from typical viewing distance; time the facilitator script | ~3–4 days before Week 2 |
| Cyber Clue Quest | Staff read 2 sample riddles aloud and solve them with the real stencil set under an actual 30-second timer; confirm the stencil set has every needed letter, including repeats | ~3–4 days before Week 4 |
| Pass-Phrase | Staff run one scramble-and-solve cycle; confirm the stencil set covers the longest phrase; confirm the timer is clearly visible to participants | ~3–4 days before Week 4 |

Cyber Clue Quest and Pass-Phrase share a rehearsal slot since they share equipment and both feed into Live Games Day — run them back-to-back with the same staff.

## 5. Comms cadence

- **Before Week 1**: campaign kickoff announcement introducing the month's theme and the Cybersecurity Game link.
- **Mid-week, Weeks 1 & 2**: reminder nudge for whichever digital game is live that week, for anyone who hasn't completed it.
- **During Week 3**: save-the-date for Live Games Day, plus a final reminder to complete both digital games before the catch-up window closes.
- **Day before Live Games Day**: reminder with time/location and team assignments if known in advance.
- **After Live Games Day**: recap and leaderboard shoutout, tying back to the deck's closing message.
