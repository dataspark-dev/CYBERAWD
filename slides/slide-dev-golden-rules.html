FOUR RULES, EVERY SINGLE TIME

AppSec Secrets Git Lifecycle AI Code Audit Prompt Injection Golden Rules

Everything in this section condenses to four habits — carry these forward into every commit, every review, every AI-assisted change.

Zero Secrets In Source Rule

No credential, key, or token ever committed to a repository — vault-managed, short-lived, and scoped, every time.

Treat AI Output As Untrusted Rule

Every AI-generated suggestion — code, a package name, a fix — gets the same verification as a stranger's contribution.

Least-Privilege By Default Rule

Every credential, service account, and deploy key scoped to only what it needs — nothing standing, nothing all-access.

MFA / Passkeys Everywhere Rule

Every account that can touch code, secrets, or production is protected by MFA or a passkey — no exceptions for how routine the access feels.

These four rules are this section's throughline — every scenario in Fault Finding, Decision Room, and the rest of this month's activities traces back to one of them being skipped.
