NOT ALL DATA NEEDS THE SAME LOCK

Hygiene Data Handling Endpoint Network AI Leakage Golden Rules

Every ticket, file, and request falls into one of four tiers — knowing which one changes how it should be handled.

Public Tier 1

Freely shareable, no restriction — marketing material, published policies, anything already meant for the outside world.

Internal Tier 2

Shared only within the company — general internal comms, non-sensitive process docs. Not for external sharing, but not high-stakes if it leaked.

Confidential Tier 3

Restricted to a defined group with a business need — customer data, financial records, internal system details. Requires access control and audit logging.

Restricted Tier 4

Highest sensitivity — credentials, encryption keys, legal/HR investigation material. Requires encryption at rest and in transit, strict access logging, and need-to-know only.

This connects directly to this month's activities: knowing a ticket or attachment's actual classification — not just its subject line — is what determines whether a request even needs the extra verification step.
Starting today: Public and Internal: normal handling, still no external Confidential data Confidential and Restricted: access control, encryption, and audit logging required When in doubt, classify one tier higher, not lower
