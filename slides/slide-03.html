MODERN THREAT LANDSCAPE

Four threats are shaping how attackers operate this year — plus one you can't fully control: your own vendors.

Ransomware

They copy your files first, then lock them. A backup restores access — the stolen copy is still theirs.

Social Engineering

Targets people, not systems — and drives most attacks in this deck.

Insider Threats

Most start as honest mistakes — a misdirected record, a reused password, leftover access.

Cloud Risks

Usually just a shared folder left open by mistake — and it can sit unnoticed for months.

1 · Vendor UpdateA software vendor we trust — fleet management, payroll, or ship systems — sends a routine update to thousands of customers, including us.
2 · Code InsertedAttackers have already breached the vendor's build pipeline and hidden malicious code inside that update before it was signed.
3 · Installed AutomaticallyThe tampered update installs through our usual update process — no phishing email required.
4 · Hidden BackdoorAttackers now have a hidden way back in, all through a vendor we already trusted. Report anything odd right after an update.
What this means for you: Back up critical data, test the restore Verify unusual requests via a 2nd channel Report mistakes immediately — no blame Double-check sharing & permissions
[REPORT] GOLDEN RULE: You can't check every vendor's code — but if something behaves oddly right after an update, treat it as suspicious and report it. Most supply-chain breaches are found months later — that's why they spread so far.
You can't inspect a vendor's internal code or process. But odd behaviour right after an update is still a visible, reportable signal — and reporting early limits the damage.
