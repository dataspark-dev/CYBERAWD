YOUR DESK IS PART OF THE PERIMETER

An unlocked dev workstation often has an active terminal, SSH agent, or cloud session already signed in — four things worth noticing here specifically, plus what should happen the moment you walk away.

Terminal With an Active Prod Session Risk

A terminal left open with an authenticated session to a production system is a bigger prize than a normal desktop login — lock it every time, even for a moment.

Screen Locked Every Time Good Practice

Lock your screen (Win+L / Cmd+Ctrl+Q) every time you step away, whether you're mid-deploy or just grabbing coffee.

Unknown USB Drive Risk

Never plug in a USB stick you don't own or haven't checked with IT — on a dev machine it can also reach an active SSH agent or cloud credential cache.

SSH Agent Not Left Forwarded/Idle Good Practice

An SSH agent with forwarding enabled on a machine you've stepped away from can be used by anyone with access to that machine — lock the screen, and don't forward agents to machines you don't fully trust.

Locking takes 2 seconds — leaving a dev workstation unlocked with an active session is an open invitation, the same as leaving a production credential itself lying around.
