WHEN ATTACKERS USE AI TOO

Every AI tool that helps you can also help an attacker. Here's the same four attack types, before and after AI.

Before AI

Generic Lures

Mass emails with poor writing, sent to thousands of addresses, hoping a few will click.

One Voice, One Script

A caller stuck with their own accent and a fixed script that doesn't adapt.

Hand-Written Malware

Code written manually — slower to make and easier for security tools to detect.

Manually Forged Paperwork

Hand-crafted fake IDs, invoices, or approval forms — time-consuming and often has visible errors.

With AI

Personalised at Scale

Flawless, tailored messages generated instantly for each target, using real names and projects.

Any Voice, Any Accent

A cloned voice — including yours or a colleague's — generated on demand for a live call.

Self-Mutating Malware

AI rewrites malicious code automatically so each copy looks different to detection tools.

AI-Generated Fake Documents

Forged IDs, invoices, or approval forms generated instantly with AI image tools — no visible errors.

WHY IT MATTERS: Old tells are disappearing. Pausing, checking on a second, trusted channel, and reporting matter more than ever.
