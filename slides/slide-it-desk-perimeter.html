IT Support — Everyday Defence

YOUR DESK IS PART OF THE PERIMETER

The IT desk sees more walk-up requests and “quick favors” than almost anyone — four things worth noticing here specifically, plus what should happen the moment you walk away from an admin session.

Admin Password on a Sticky Note Risk

An admin credential written down anywhere near a desk is worse than a normal password sticky note — it opens far more than one account. Use the vault, never a note.

Admin Session Locked Every Time Good Practice

An open admin console or ticketing system left unlocked, even for a moment, is a bigger prize than a normal desktop — lock it every single time.

Unknown USB Drive for “Diagnostics” Risk

A USB drive someone hands you for a “quick fix” goes through the same intake check as any other unknown device — IT's own workstation is not exempt from IT's own rule.

Server Room / Network Closet Access Logged Good Practice

Anyone entering a server room or network closet is logged and badged in individually — no holding the door, no exceptions for a familiar face.

Same rule at any privileged workstation: locking takes 2 seconds — leaving an admin session open is an open invitation to whoever walks past next.
Starting today: Lock every admin session, even for a moment Admin credentials live in the vault, never on a note Log and badge every entry to a server room or network closet
