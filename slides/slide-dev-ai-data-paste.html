Never paste a stack trace with real data, a .env file, an API key, or customer records into a public chatbot — even to debug faster.
Use only company-approved AI coding assistants — they're reviewed for exactly this risk, including where your code and data actually go.
GDPR: Customer data embedded in test fixtures, logs, or a bug report must stay inside approved, contracted systems — pasting it into a public AI tool to debug can itself be a data protection breach.
