TWO WAYS TO THINK ABOUT AI SECURITY

Every engineer on this team touches AI from at least one of these two angles — often both.

1. Using AI Coding Tools

Developer workflow risks with AI IDE plugins and copilots.

  • Reviewing AI code generation
  • Preventing code/secret leakage

2. Building AI Applications

System architecture risks when integrating LLMs and APIs.

  • Prompt injection & tool abuse
  • Token limits & authorization
[AI SECURITY] GOLDEN RULE: Whether you're using an AI coding assistant or building an AI-powered feature, the same discipline applies — treat AI output as untrusted, and treat anything an AI feature reads as untrusted input too.
