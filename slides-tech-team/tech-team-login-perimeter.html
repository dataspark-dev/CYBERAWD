YOUR LOGIN IS PART OF THE PERIMETER

What a well-protected account looks like — your admin console, your git hosting, your cloud console, and the credentials and keys that stand in for a password.

Reused Password or SSH Key Without a Passphrase Risk

Reusing a password on a privileged account, or an SSH key with no passphrase, is a single leak or stolen laptop away from full access — every credential gets its own protection, no exceptions.

Hardware MFA Everywhere That Matters Good Practice

A hardware key (FIDO2) on admin consoles, git hosting, and your cloud provider stops a phished password from getting in — software MFA alone is a lower bar for accounts that need the highest one.

Unrecognised Sign-In Ignored Risk

An unrecognised sign-in to an admin console, source control, or a cloud console is a critical incident, not a routine alert — treat it and report it as such immediately.

MFA Push-Bombing

A flood of approval requests you didn't trigger, on any account, is an attack, not a glitch — tap Deny, not Approve, and report it immediately.

If a prompt looks wrong, deny and report.
