SHADOW AI — THE UNAPPROVED TOOLS

Shadow AI — any AI tool used for work that hasn't been reviewed or approved. Chatbots aren't the only one, and IT's and Engineering's own tools aren't exempt.

Browser AI Extensions

Free “AI assistant” add-ons read every page you open — including internal dashboards, admin consoles, and repos. If it isn't approved, remove it.

Personal AI Accounts

A personal account instead of the company one sits outside our data agreements — no protection, no oversight.

AI Meeting Note-Takers

Bots that auto-transcribe send everything said — including change-approval, architecture, and incident-review calls — to a third-party server.

Unapproved AI Diagnostic/Scanning Tools

A free “AI-powered” network scanner, log analyser, or config-checker can send infrastructure details and credentials to a third-party server outside the approved system.

Unapproved AI Coding Extensions

A free AI coding add-on not on the approved list can send source code, including proprietary logic and embedded secrets, to a third-party server on every keystroke.

Not sure whether a tool is approved? Ask before using it with company, customer, credential, or code data — asking is always safe.
If you spot one: Stop using it on company code or data Asking is safe — unchecked use isn't
