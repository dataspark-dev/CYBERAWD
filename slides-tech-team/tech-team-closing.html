This playbook connects the CIA triad through developer hygiene to the AI systems your team is already building — security is a daily habit, not a one-time review.

CIA Triad
Confidentiality, integrity, and availability — every control in this playbook maps back to one of these three.
Enterprise Hygiene
Hardware MFA, least privilege, zero trust, automated patching — six baseline controls, applied everywhere.
Phishing & Verification
Urgency is the tell. Verify unusual requests through a channel you already trust, never one the requester supplies.
Endpoint & Network
Patch automatically, encrypt every disk, run as standard user by default, and trust no network location by itself.
Data Classification
Handling follows classification, not convenience — four tiers, each with its own requirement.
Secrets Architecture
Every secret in a vault, short-lived and scoped — never in source, a frontend, or an unencrypted .env file.
Git Lifecycle Defense
Defense at every stage — pre-commit, pull request, and instant revocation on any leak.
AppSec Essentials
Validate every input server-side, authorize every request, sanitize every query.
AI Security Architecture
Treat AI output as untrusted, sanitize what it reads, gate every prompt through the same four checkpoints.
Resource & Data Defense
Token limits, tenant quotas, RAG access control, and strict telemetry/masking separation.
Golden Rules
MFA everywhere, zero secrets in source, AI output untrusted, least privilege by default.
A hardcoded key, an unverified request, or an untrusted AI output is not proof of safety: STOP → VERIFY through a channel you already trust → REPORT. Every single time.
