Technology Team — Core Takeaways

THE 4 GOLDEN RULES OF SECURITY HYGIENE

Everything in this playbook condenses to four habits — carry these forward into every system you touch.

Rule 01 — MFA & Passkeys Everywhere Rule

FIDO2 hardware authentication across every service and repository.

Rule 02 — Zero Secrets in Source Code Rule

Centralized vaulting and automated pre-commit scanning.

Rule 03 — Treat AI Output as Untrusted Rule

Validate and authorize AI decisions outside the model boundary.

Rule 04 — Enforce Least Privilege Rule

Strictly scope agent permissions and gate high-impact operations.

[GOLDEN RULES] These four rules are this playbook's throughline — every standard and every architecture pattern traces back to one of them.
