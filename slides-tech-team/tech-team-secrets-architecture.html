SECRETS ARCHITECTURE STANDARDS

Where a credential lives is a security decision, not a convenience one.

Forbidden Practices
  • Hardcoded keys inside source code repositories.
  • Embedding static API tokens in mobile or web frontends.
  • Committing unencrypted .env configuration files.
Approved Vault Standard
  • Inject runtime credentials via KMS or HashiCorp Vault.
  • Short-lived ephemeral tokens with automated 30-day rotation.
  • Scoped IAM environment variables per deployment environment.
[SECRETS] GOLDEN RULE: Treat every secret as radioactive — it belongs in a vault with a short lifetime and a narrow scope, never in source, a frontend bundle, or an unencrypted .env file.
