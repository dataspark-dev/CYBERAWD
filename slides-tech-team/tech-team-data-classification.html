DATA CLASSIFICATION MATRIX

Every ticket, file, and request falls into one of four tiers — knowing which one changes how it should be handled.

Tier Examples Handling Requirement
PublicMarketing content, open APIsSafe for public web distribution
InternalInternal wikis, employee listsRestricted to authenticated staff
ConfidentialSource code, customer PIIEncrypted at rest and in transit
RestrictedAPI keys, private keys, database dumpsStrict Vault access; zero external pasting
[DATA CLASSIFICATION] GOLDEN RULE: Handling follows classification, not convenience — when in doubt, classify one tier higher, not lower.
