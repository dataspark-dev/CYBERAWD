FOUR RULES, EVERY SINGLE TIME

Hygiene Data Handling Endpoint Network AI Leakage Golden Rules

Everything in this section condenses to four habits — carry these forward into every ticket, every access request, every AI-assisted decision.

Hardware MFA Everywhere Rule

Every privileged account protected by a FIDO2 hardware key or passkey — no exceptions for convenience.

Zero Secrets In Chat/Tickets Rule

No credential, password, or key ever pasted into a chat message, ticket, or ticket attachment — use the vault and its proper handoff process instead.

AI-Assisted Decisions Need Human Authorization Rule

An AI tool can help triage or draft a response — it never gets the final say on a privileged action. A human authorizes it.

Least Privilege On Every Access Request Rule

Every access request — a reset, an elevation, a new grant — is scoped to exactly what's needed, reviewed the same way regardless of who's asking.

These four rules are this section's throughline — every scenario in Fault Finding, Decision Room, and the rest of this month's activities traces back to one of them being skipped.
