An AI feature without resource limits is a billing incident waiting to happen.

Rate

Tenant Quotas

Enforce hourly request ceilings per authenticated user or service.

Alert

Circuit Breakers

Auto-kill on any billing anomaly that crosses a threshold — don't wait for a human to notice.

[CONTAIN COST] GOLDEN RULE: Token limits, per-user quotas, and automatic circuit breakers are the same discipline as rate-limiting any other API — an AI endpoint is not exempt just because the cost model is newer.
