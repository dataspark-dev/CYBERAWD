PROMPT INJECTION VECTORS

Building with AI is different from just using an AI tool — the content your feature reads becomes something an attacker can talk to.

Direct Prompt Injection Vector

Malicious user input directly overriding the system's own instructions.

Indirect Prompt Injection Vector

An attacker's payload embedded in an external PDF, website, or RAG document the model retrieves.

Starting today: Treat every retrieved document or website as untrusted input Constrain what actions an AI feature's model can actually take
[PROMPT INJECTION] GOLDEN RULE: If your feature reads external content and acts on what it finds, that content is now part of your attack surface.
